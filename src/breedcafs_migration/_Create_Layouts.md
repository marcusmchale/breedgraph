## Create Layouts
using the [field layout types](../data/breedcafs_migration/field_layout_types.csv)
construct all matching layouts.

Row and Tree means a "Row and Tree" type layout on the Field, unless Row and Tree per block is set.
Row and Tree per Block means a "Row and Tree" type layout on each Block.
Row, Tree and Stratum means a "Row, Tree and Stratum" type layout on each field, regardless of other layouts.

This allows for either recording tree positions using the Row + Tree layout, or recording branch positions using the 
Row, Tree and Stratum layout.
