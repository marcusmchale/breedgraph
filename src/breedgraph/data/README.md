# Data packaged with BreedGraph

- `credit_roles.csv`: the CRediT contributor roles (https://credit.niso.org).
- `countryInfo.txt`: GeoNames' country list (https://download.geonames.org/export/dump/countryInfo.txt), as GeoNames
  publishes it, under the Creative Commons Attribution 4.0 licence (https://creativecommons.org/licenses/by/4.0/):
  the countries a location tree can start from (`breedgraph.adapters.geonames.countries`). Update it by downloading it
  again.
