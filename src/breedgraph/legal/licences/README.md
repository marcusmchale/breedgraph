# Standard licences

The legal code of the licences every deployment starts with, as Creative Commons publishes it in plain text, fetched
on 29 October 2026:

- `cc-by-4.0.txt`: Creative Commons Attribution 4.0 International, from
  https://creativecommons.org/licenses/by/4.0/legalcode.txt
- `cc0-1.0.txt`: Creative Commons CC0 1.0 Universal, from
  https://creativecommons.org/publicdomain/zero/1.0/legalcode.txt

Creative Commons dedicates the text of its licences to the public domain under CC0, so they are packaged unchanged.
`service_layer/application/licence_seed.py` seeds them as legal references without controls, which no one can change
(docs/licences.md §6). A changed file would be a different licence, with a different content hash: don't edit them.
